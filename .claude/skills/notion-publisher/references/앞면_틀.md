# 앞면 틀 (The Daily Paper)

표지 페이지를 replace_content로 그날 호로 바꿀 때 이 틀을 따른다. 디자인 기준은 `design/design_handoff_daily_paper`의 "노션 · 오늘 호"(호 줄 → 요약 콜아웃 → 오늘의 머리기사 카드 → 논문 서점).
`{ }` 칸만 그날 값으로 채우고, 나머지 줄은 **글자 그대로** 둔다. 들여쓰기는 탭이다.

- **키워드 색**: 아래 `{색}`은 아카이브 `키워드` 선택지의 색을 그대로 쓴다(fetch한 data source에서 확인, 표지와 서점의 색이 같게). 선택지 색은 SKILL.md "아카이브 맞추기"가 디자인 순서(red → green → blue → orange → purple → pink → brown)로 맞춰 둔다.
- `{머리기사 카드}`: 그날 논문 전부를 요약한 논문 먼저(ID 순), 다음 요약 안 한 논문(ID 순)으로 **세 편씩** 한 `<columns>`에 담는다. 마지막 줄이 세 편보다 적으면 그 편수만큼만 column을 둔다. 카드 모양은 아래 "카드".
- `{요약 줄}`의 편수는 `목록.json`으로 센다. 조테로를 쓰지 않으면 "조테로 N편"을 빼고, 요약을 쓰지 않으면 "요약 N편"을 빼고 카드는 모두 후보 모양이다.
- `{아카이브 줄}`: replace_content 전에 fetch한 표지에서 `<database …>논문 아카이브</database>` 줄을 찾아 **글자 그대로** 옮긴다. 주소를 지어내거나 새로 만들지 않는다. 그 줄이 없으면 표지를 바꾸지 말고 "표지에 아카이브 데이터베이스가 없음"으로 실패를 보고한다.
- 표지·아이콘은 바꾸지 않는다(cover, icon 인자를 넘기지 않는다). 아이콘은 새로 시작 때 한 번 정한다.

## 앞면

```
<span color="gray">**NO.{세 자리 호수}**  ·  {YYYY년 M월 D일 X요일}  ·  키워드 </span><span color="{색1}">**{키워드1}**</span><span color="gray"> · </span><span color="{색2}">**{키워드2}**</span>
<callout icon="📰" color="brown_bg">
	**{요약 줄: 수집 N편 · 요약 M편 · 조테로 Z편 · 오픈 액세스 O편}**
	<span color="gray">결과의 숫자는 원문 그대로이고, 항목마다 §·쪽·Table 근거가 붙습니다. 후보 논문은 사람이 원문을 확인하기 전까지 근거로 쓰지 않습니다.</span>
</callout>
## 오늘의 머리기사
{머리기사 카드}
---
## 논문 서점
{아카이브 줄}
<span color="gray">지난 호도 모두 여기에 쌓입니다 · 신간 매대 · 키워드별 서가 · 읽기 상태별 · 표 · OpenAlex·Exa에서 수집 · 조테로에 저장 · paper-reader 요약</span>
```

## 카드 (논문 1편)

`{짧은 제목}`은 아카이브의 `짧은 제목` 칸 값, `{페이지 URL}`은 그 논문의 아카이브 페이지. 머리기사(아카이브 `머리기사` 체크)인 카드는 아이콘을 ⭐로 바꾼다.

요약한 논문(세 편이 한 줄이면 column 세 개):
```
<columns>
	<column>
		<callout icon="📗" color="gray_bg">
			<span color="{색}">**{키워드 대문자}**</span>
			**[{짧은 제목}]({페이지 URL})**
			{결과 한 줄}
			<span color="gray">{저자 약칭} · {출처 짧게}</span>
		</callout>
	</column>
</columns>
```

요약하지 않은 논문(후보)은 callout만 이렇게 바꾼다:
```
		<callout icon="📙" color="gray_bg">
			<span color="{색}">**{키워드 대문자}**</span>
			**[{짧은 제목}]({페이지 URL})**
			<span color="gray">*후보 논문입니다. 사람이 원문을 확인하기 전에는 초안의 근거로 쓰지 않습니다.*</span>
		</callout>
```

## 창간 준비호 (노션 새로 시작 때 한 번)

첫 호가 나오기 전 표지. 키워드는 `설정/paper-scout.json`에서, `{아카이브 줄}`은 방금 만든(또는 찾은) 데이터베이스 줄.

```
<span color="gray">**NO.000**  ·  창간 준비호  ·  키워드 </span><span color="{색1}">**{키워드1}**</span><span color="gray"> · </span><span color="{색2}">**{키워드2}**</span>
<callout icon="📰" color="brown_bg">
	**The Daily Paper를 준비했습니다.** 매일 관심 키워드로 새 논문을 찾아 이 표지를 그날 호로 바꾸고, 논문은 아래 논문 서점에 한 권씩 꽂습니다.
	<span color="gray">첫 호는 대시보드의 "지금 논문 찾기"나 예약 실행, 또는 작업공간 세션의 "오늘 논문 찾아 줘"로 나옵니다.</span>
</callout>
## 논문 서점
{아카이브 줄}
<span color="gray">지난 호도 모두 여기에 쌓입니다 · OpenAlex·Exa에서 수집 · 조테로에 저장 · paper-reader 요약</span>
```
