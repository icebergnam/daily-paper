# 앞면 틀 (The Daily Paper)

표지 페이지를 replace_content로 그날 호로 바꿀 때 이 틀을 따른다.
`{ }` 칸만 그날 값으로 채우고, 나머지 줄(이미지·데이터베이스·꼬리말)은 **글자 그대로** 둔다. 들여쓰기는 탭이다.

- `{요약 블록}`: 요약한 논문을 키워드별로, 논문마다 아래 "요약 블록" 모양을 반복한다. 같은 키워드의 둘째 논문부터는 빨간 키워드 줄을 빼고 `---`로 나눈다.
- `{함께 목록}`: 요약하지 않은 논문마다 `- <mention-page url="{페이지 URL}"/> <span color="gray">— {첫 저자 성} 외 · {출처 짧게}</span>`. 없으면 `- <span color="gray">없음</span>`.
- 조테로 미저장이면 `<span color="green">✓ 조테로 저장</span>` 대신 `<span color="red">조테로 미저장</span>`. 오픈 액세스가 없으면 그 링크를 뺀다.
- `{아카이브 줄}`: replace_content 전에 fetch한 표지에서 `<database …>논문 아카이브</database>` 줄을 찾아 **글자 그대로** 옮긴다. 주소를 지어내거나 새로 만들지 않는다. 그 줄이 없으면 표지를 바꾸지 말고 "표지에 아카이브 데이터베이스가 없음"으로 실패를 보고한다.
- 표지·아이콘은 바꾸지 않는다(cover, icon 인자를 넘기지 않는다).

## 앞면

```
<span color="gray">**NO.{세 자리 호수}**  ·  {YYYY년 M월 D일 X요일}  ·  오늘의 키워드 </span><span color="red">**{키워드1}**</span><span color="gray"> · </span><span color="red">**{키워드2}**</span>
---
<columns>
	<column ratio="64">
		{요약 블록}
	</column>
	<column ratio="36">
		<callout icon="🗞️" color="brown_bg">
			**이번 호**
			<table header-column="true" fit-page-width="true">
				<tr>
					<td>수집</td>
					<td>{N}편</td>
				</tr>
				<tr>
					<td>요약</td>
					<td>{M}편</td>
				</tr>
				<tr>
					<td>조테로</td>
					<td>{저장 수}편</td>
				</tr>
				<tr>
					<td>오픈 액세스</td>
					<td>{OA 수}편</td>
				</tr>
			</table>
		</callout>
		<span color="gray">**함께 들어온 논문**</span>
		{함께 목록}
		<span color="gray">*후보 논문입니다. 사람이 원문을 확인하기 전에는 초안의 근거로 쓰지 않습니다.*</span>
	</column>
</columns>
---
<span color="gray">**지난 호 · 아카이브**</span>
{아카이브 줄}
<span color="gray">OpenAlex·Exa에서 수집 · 조테로에 저장 · paper-reader 요약</span>
```

## 창간 준비호 (노션 새로 시작 때 한 번)

첫 호가 나오기 전 표지. 키워드는 `설정/paper-scout.json`에서, `{아카이브 줄}`은 방금 만든(또는 찾은) 데이터베이스 줄.

```
<span color="gray">**NO.000**  ·  창간 준비호  ·  오늘의 키워드 </span><span color="red">**{키워드1}**</span><span color="gray"> · </span><span color="red">**{키워드2}**</span>
---
<callout icon="🗞️" color="brown_bg">
	**The Daily Paper를 준비했습니다.** 매일 관심 키워드로 새 논문을 찾아 이 표지를 그날 호로 바꾸고, 논문은 아래 아카이브에 한 줄씩 쌓습니다.
	<span color="gray">첫 호는 작업공간 세션에서 "오늘 논문 찾아 줘"를 보내거나 예약 실행 때 나옵니다.</span>
</callout>
---
<span color="gray">**지난 호 · 아카이브**</span>
{아카이브 줄}
<span color="gray">OpenAlex·Exa에서 수집 · 조테로에 저장 · paper-reader 요약</span>
```

## 요약 블록 (논문 1편, column 안이라 탭 두 개로 시작)

```
		<span color="red">**{키워드 대문자}**</span>
		## <mention-page url="{아카이브에 만든 페이지 URL}"/>
		> *{결과 한 줄}*
		<span color="gray">**{저자, 쉼표로}** — {연도} · {출처}</span>
		<span color="green">✓ 조테로 저장</span>  ·  [오픈 액세스 원문]({oa_url})  ·  [DOI]({url})
		<details>
		<summary>**요약 전문 읽기**</summary>
			<table header-column="true" fit-page-width="true">
				<tr>
					<td>연구 질문</td>
					<td>{D*.md 연구 질문}</td>
				</tr>
				<tr>
					<td>방법</td>
					<td>{D*.md 방법}</td>
				</tr>
				<tr>
					<td>결과</td>
					<td>{D*.md 결과}</td>
				</tr>
				<tr>
					<td>한계</td>
					<td>{D*.md 저자가 밝힌 한계}</td>
				</tr>
			</table>
		</details>
```
