# 아카이브 한 줄 (논문 1편)

## 칸

| 칸 | 값 |
|---|---|
| 제목 | title |
| 날짜 | 그날 날짜 |
| 키워드 | 맞은 키워드. 선택지에 없으면 data source에 선택지를 먼저 추가 |
| 결과 한 줄 | 요약한 논문만: D*.md의 "결과:" 줄을 한 문장으로 |
| 저자 | 쉼표로 |
| 연도 · 출처 | year · venue |
| 요약 | 요약했으면 체크 |
| 조테로 저장 | zotero_saved |
| 원문 · 오픈 액세스 | url · oa_url(없으면 비움) |

아이콘은 📄.

## 요약한 논문의 본문

```
> *{결과 한 줄}* {color="gray"}
<callout icon="📜" color="brown_bg">
	**{요약 기준}** — 사람이 확인하기 전에는 초안의 근거로 쓰지 않습니다.
</callout>
### 연구 질문 {color="red"}
{D*.md 연구 질문}
### 방법 {color="red"}
{D*.md 방법}
### 결과 {color="red"}
{D*.md 결과}
### 한계 {color="red"}
{D*.md 저자가 밝힌 한계}
---
[DOI · 출처]({url}) · [오픈 액세스 원문]({oa_url}) {color="gray"}
```

`{요약 기준}`은 D*.md 맨 위 ※ 줄 그대로(원문 PDF 기준 요약 / 웹 본문 기준 요약 / 초록 기준 요약). D*.md의 근거 표시 "(초록)"은 빼고, 절·쪽 표시는 둔다.

## 요약하지 않은 논문의 본문

```
<callout icon="🗞️" color="gray_bg">
	함께 들어온 논문입니다. 이날은 요약하지 않았습니다.
</callout>
[DOI · 출처]({url}) · [오픈 액세스 원문]({oa_url}) {color="gray"}
```
