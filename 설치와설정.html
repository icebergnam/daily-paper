매일 논문 설치와 설정

관심 키워드로 매일 새 논문을 찾아 조테로에 저장하고, PDF를 읽고 요약해서, 노션 The Daily Paper에 올리는 Claude 에이전트입니다.

Claude가 할 수 없는 것만 먼저 설치하고(1부, 20분), 나머지는 Claude에게 아래 문장을 차례로 보내면 Claude가 설정합니다(2부, 10분).

결과는 후보 논문입니다. 원문을 읽기 전에는 논문의 근거로 쓰지 않습니다.

1부 · 미리 설치할 것2부 · Claude로 설정하기

1부미리 설치할 것

계정 만들기, 로그인, 앱 설치, 화면의 “허용”은 Claude가 대신하지 않습니다. 끝낸 항목을 체크하세요(이 브라우저에 기억됩니다).

  • Claude 데스크톱 앱 Pro 이상 claude.ai/download에서 설치하고 로그인합니다. Code 탭과 예약 작업을 씁니다.
  • python3 터미널에서 python3 --version을 입력합니다. “명령어 라인 개발자 도구를 설치하겠습니까?” 창이 뜨면 설치를 누릅니다. 버전 번호가 나오면 끝입니다.
  • 조테로 7 저장하려면 zotero.org/download에서 설치하고 켭니다. 왼쪽 내 라이브러리를 오른쪽 클릭 → 새 컬렉션 → 이름 자동수집(띄어쓰기 없이). 매일 실행할 때 조테로 앱이 켜져 있어야 저장됩니다.
  • 노션 가입 notion.com 무료 요금제로 됩니다.
  • Claude 커넥터 연결 claude.ai → 설정 → 커넥터에서 Notion(필수, 내 워크스페이스 접근 허용)과 Exa(권장)를 연결합니다. 목록에 Exa가 없으면 Claude 앱의 플러그인 목록에서 Exa 플러그인을 설치해도 됩니다.
  • 이 저장소를 받아 폴더 열기 git clone 저장소주소 또는 GitHub의 Code → Download ZIP으로 받습니다. Claude 앱 Code 탭 → 폴더 선택에서 CLAUDE.md가 보이는 폴더를 열고, “이 폴더를 신뢰하겠습니까”에 신뢰, 권한 모드는 수동으로 둡니다.
  • Mac 알림 허용 선택 매일 결과를 알림으로 받으려면 시스템 설정 → 알림에서 막혀 있지 않은지 봅니다. 처음 알림이 안 뜨면 여기부터 확인합니다.

설정해 줘

  1. 시작하기

    Claude가 연구실 규정상 이 폴더에 넣으면 안 되는 자료를 묻습니다. 모르면 “모름”이라고 답합니다.

    시작

    끝나면 “설정을 저장했습니다”

  2. 설치 확인

    1부에서 빠뜨린 것이 있는지 Claude가 점검 스크립트로 확인합니다.

    설치 확인해 줘. python3 scripts/설정점검.py를 돌리고, 미리 설치할 것 중 빠진 것만 설치 방법과 함께 알려 줘.

    ❌ 줄은 다음 단계에서 하나씩 없어집니다. ✅ 파이썬 · ✅ 조테로가 보이면 됩니다.

  3. 커넥터 이름 맞추기

    담당 파일의 커넥터 이름은 계정마다 달라서 빈칸으로 들어 있습니다. Claude가 내 계정의 이름으로 채웁니다.

    담당 파일의 커넥터 빈칸을 채워 줘. 지금 쓸 수 있는 Notion(fetch·notion-create-pages·notion-update-page·notion-update-data-source)과 Exa(web_search_exa·web_fetch_exa) 도구의 실제 이름 앞부분(mcp__…__)을 찾아 .claude/agents/의 mcp__NOTION_ID__, mcp__EXA_ID__ 자리를 바꿔 줘. 연결되지 않은 커넥터는 그대로 두고 알려 줘.

  4. 노션 신문 만들기

    내 노션에 The Daily Paper 페이지와 논문 아카이브 데이터베이스를 만들고, 주소를 설정에 적습니다.

    내 노션 개인 페이지에 "The Daily Paper" 페이지를 만들고, 그 안에 인라인 데이터베이스 "논문 아카이브"를 만들어 줘. 칸: 제목(제목), 날짜(날짜), 키워드(선택), 결과 한 줄(텍스트), 저자(텍스트), 연도(숫자), 출처(텍스트), 요약(체크박스), 조테로 저장(체크박스), 원문(URL), 오픈 액세스(URL). 만든 데이터베이스 주소를 설정/매일논문.json의 notion_db_url에 넣고, 데이터베이스 주소와 collection:// 주소를 .claude/skills/daily-paper-format/references/앞면_틀.md의 {아카이브_DB_URL}, {아카이브_DATA_SOURCE_URL} 자리에 넣어 줘.

    노션에 The Daily Paper 페이지가 생깁니다. 표지 이미지는 원하면 직접 넣습니다.

  5. 새 세션에서 연결 점검

    담당 파일과 판정 훅은 세션을 시작할 때 읽힙니다. 사이드바에서 새 세션을 열고 보냅니다.

    연결 점검해 줘: 설정/매일논문.json의 notion_db_url을 Notion fetch로 열어 "논문 아카이브" 데이터베이스가 보이는지, Exa 도구가 도구 목록에 있는지만 확인해 줘. 아무것도 쓰거나 검색하지 마.

    “논문 아카이브가 보인다” · “Exa 도구가 있다”

  6. 키워드 정하기

    [ ] 안을 내 관심 분야로 바꿔 보냅니다. 영어로 2~3단어짜리 구가 좋고, 너무 넓으면(AI) 엉뚱한 논문이 나옵니다.

    내 관심 분야는 [여기에 적기]야. 매일 논문 영어 키워드를 3개 제안해 줘. 내가 고르면 설정/매일논문.json에 적어 줘.

  7. 검색만 시험하기

    조테로에 저장하지 않고, 키워드가 논문을 잘 찾는지만 봅니다.

    검색만 한 번 해 줘. python3 scripts/매일논문.py 검색으로 후보를 찾고 제목만 보여 줘.

    제목이 관심사와 맞지 않으면 6단계로 돌아가 키워드를 바꿉니다.

  8. 처음 실행하기

    조테로 앱을 켜 두고 보냅니다. 5~10분 걸리고, 허용 창(python3 실행, Exa 검색어, 노션 쓰기)이 여러 번 뜹니다.

    오늘 논문 찾아 줘

    PDF를 받은 논문만 요약하고(못 받으면 다음 후보로), 판정을 통과해야 노션에 올립니다. 끝나면 노션 앞면 NO.001 · 조테로 자동수집 · Mac 알림

    알림에 “판정 실패로 노션 미업로드”가 뜨면, 요약이 판정 기준을 3번 안에 통과하지 못한 것입니다. 매일논문/날짜/판정기록.md를 Claude에게 보여 주고 물어보세요.
