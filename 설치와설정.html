매일 논문 설치와 설정

관심 키워드로 매일 새 논문을 찾아 조테로에 저장하고, PDF를 읽고 요약해서, 노션 The Daily Paper에 올리는 Claude 에이전트입니다.

Claude가 할 수 없는 것만 먼저 설치하고(1부, 20분), 나머지는 Claude에게 “설정해 줘” 한 마디만 보내면 Claude가 묻고 설정합니다(2부, 10분).

결과는 후보 논문입니다. 원문을 읽기 전에는 논문의 근거로 쓰지 않습니다.

1부 · 미리 설치할 것2부 · Claude로 설정하기

1부미리 설치할 것

계정 만들기, 로그인, 앱 설치, 화면의 “허용”은 Claude가 대신하지 않습니다. 끝낸 항목을 체크하세요(이 브라우저에 기억됩니다).

  • Claude 데스크톱 앱 Pro 이상 claude.ai/download에서 설치하고 로그인합니다. Code 탭과 예약 작업을 씁니다.
  • python3 터미널에서 python3 --version을 입력합니다. “명령어 라인 개발자 도구를 설치하겠습니까?” 창이 뜨면 설치를 누릅니다. 버전 번호가 나오면 끝입니다.
  • 조테로 7 저장하려면 zotero.org/download에서 설치하고 켭니다. 왼쪽 내 라이브러리를 오른쪽 클릭 → 새 컬렉션 → 이름 자동수집(띄어쓰기 없이). 매일 실행할 때 조테로 앱이 켜져 있어야 저장됩니다.
  • 노션 가입 notion.com 무료 요금제로 됩니다.
  • Claude 커넥터 연결 claude.ai → 설정 → 커넥터에서 Notion(필수, 내 워크스페이스 접근 허용)과 Exa(권장)를 연결합니다. 목록에 Exa가 없으면 Claude 앱의 플러그인 목록에서 Exa 플러그인을 설치해도 됩니다.
  • 이 저장소를 받아 폴더 열기 git clone 저장소주소 또는 GitHub의 Code → Download ZIP으로 받습니다. Claude 앱 Code 탭 → 폴더 선택에서 CLAUDE.md가 보이는 폴더를 열고, “이 폴더를 신뢰하겠습니까”에 신뢰, 권한 모드는 수동으로 둡니다.
  • Mac 알림 허용 선택 매일 결과를 알림으로 받으려면 시스템 설정 → 알림에서 막혀 있지 않은지 봅니다. 처음 알림이 안 뜨면 여기부터 확인합니다.

2부Claude로 설정하기

받은 저장소 폴더를 Code 탭에서 열고 아래 한 마디만 보냅니다. Claude가 기본(로그인·작업공간)을 갖춘 뒤 담당 에이전트 순서(찾기 → 조테로 → 요약 → 노션)로 담당마다 필요한 것만 묻고 진행합니다. 7단계입니다. 허용 창이 뜨면 내용을 보고 허용합니다. 키·토큰은 대화창에 붙여넣지 않습니다(Claude도 묻지 않습니다).

이 한 마디면 됩니다

중간에 멈췄으면 같은 문장을 다시 보내세요. 끝난 단계는 건너뜁니다.

설정해 줘

  1. 기본 · Claude Code 로그인과 설치 점검

    Claude가 Claude Code 로그인, python3, 담당마다 필요한 것(Exa 커넥터, 조테로 7과 자동수집 컬렉션, 노션 가입·Notion 커넥터)을 링크와 함께 보여 주고, python3 scripts/설정점검.py 설치와 세션의 도구 목록으로 확인합니다. 빠진 것만 다시 안내합니다.

    사람이 할 일: 빠진 것 설치하고 “했어”. ✅ Claude Code · ✅ 파이썬 · ✅ Notion이면 다음으로

    커넥터를 이 대화를 연 뒤에 연결했다면, 사이드바에서 같은 폴더로 새 세션을 열고 다시 “설정해 줘”를 보냅니다.

  2. 기본 · 작업공간 만들기

    개인 값(키워드·노션 주소)과 매일 받는 논문을 git에 올라가지 않게 두려고, 저장소 안에 workspace 폴더(.gitignore로 뺌)를 만들자고 제안합니다. 승인해야 만들고, 다른 경로를 말해도 됩니다.

    사람이 할 일: 경로 확인 후 승인

  3. 찾기 · paper-scout

    Claude가 paper-scout에 Exa 커넥터 이름을 채웁니다. 관심 연구 분야를 한국어로 한두 문장 답하면 영어 검색 키워드 2~3개를 만들고 검색을 한 번 돌려 위쪽 제목을 보여 줍니다. 엉뚱한 논문이 많으면 더 좁힌 키워드를 제안합니다.

    사람이 할 일: 관심 분야 답하기, 제목 보고 “좋아” 또는 “좁혀 줘”

  4. 조테로 · zotero-keeper (선택)

    쓸지 먼저 정합니다. 쓰면 zotero-keeper가 고른 논문을 조테로 컬렉션(기본 자동수집)에 저장하고, 시험으로 한 편을 시험 태그로 실제로 저장해 봅니다.

    ✅ 조테로 앱 · ✅ 자동수집 컬렉션. 조테로를 안 쓰면 건너뛰어도 됩니다

  5. 요약 · paper-reader (선택)

    쓸지 먼저 정합니다. 쓰면 받은 논문 중 몇 편을 요약할지(기본 2편) 정하고, 시험으로 한 편을 실제로 요약해 판정 기준으로 점검합니다. 요약은 PDF를 받은 논문만 합니다. 안 쓰면 노션에는 초록만 올라갑니다.

    사람이 할 일: 쓸지 답하기, 시험 실행

  6. 노션 · privacy-guard → notion-publisher (필수)

    privacy-guard가 올리기 전에 볼 “넣으면 안 되는 자료”를 확인하고, 시험으로 실제 결과는 통과시키고 가짜 민감 자료는 막는지 봅니다. 노션에서 빈 페이지를 하나 만들고 오른쪽 위 ··· → 링크 복사로 주소를 넣고 새로 시작을 누르면, notion-publisher가 그 안에 논문 아카이브(11칸)와 표지를 만들고 시험 줄 한 편을 올려 봅니다.

    노션 페이지 안에 논문 아카이브 표가 생기고, 시험이 통과

  7. 연결 시험 · 담당 전부 한 번에

    담당과 판정 훅은 세션을 시작할 때 읽히므로, Claude가 작업공간 폴더로 새 세션을 열어 오늘 논문 찾아 줘를 보냅니다(못 열면 직접 열라고 안내). 담당이 찾기 → 조테로 → 요약 → 노션 순서로 이어서 일합니다. 조테로 앱을 켜 두세요. 5~10분 걸립니다.

    끝나면 노션 앞면 NO.001 · 조테로 자동수집 · Mac 알림

    알림에 “판정 실패로 노션 미업로드”가 뜨면, 요약이 판정 기준을 3번 안에 통과하지 못한 것입니다. 매일논문/날짜/판정기록.md를 Claude에게 보여 주고 물어보세요.

앞으로는 작업공간 폴더에서 대시보드(python3 scripts/대시보드.py)를 열어 씁니다. 매일 자동으로 돌리려면 현황의 매일 예약에서 시각을 정하세요(그 시각에 Mac이 켜져 있어야 합니다).

설정을 다시 확인하려면 작업공간 세션에서 설정 점검해 줘 · 키워드 바꾸기: 매일 논문 키워드를 ○○, ○○로 바꿔 줘 · 문제가 생기면 증상을 그대로 Claude에게 말하세요.
