# 매일 논문 (The Daily Paper)

관심 키워드로 매일 새 논문을 찾아 **조테로에 저장**하고, **요약**해서, **노션**에 신문처럼 올립니다.
**Claude Code 에이전트**가 담당을 나눠 일합니다. 파이썬은 웹 대시보드와 담당 스킬 안의 작은 스크립트(OpenAlex 검색·조테로 저장·PDF 받기·판정)뿐입니다.

```
paper-scout(OpenAlex·Exa 검색, 관계없는 후보 거르기) → 고르기·PDF → zotero-keeper(선택) → paper-reader(선택, 병렬)
→ 다이제스트 → 판정 루프 → privacy-guard → notion-publisher(The Daily Paper) → 알림
```

## 무엇이 들어 있나

| 위치 | 내용 |
|---|---|
| `CLAUDE.md` | 규칙, 담당표, 호출표. Claude가 세션마다 읽습니다 |
| `.claude/agents/` | 담당 5명: `paper-scout`(OpenAlex·Exa 검색·거르기·본문), `zotero-keeper`(조테로 저장, 선택), `paper-reader`(요약, 선택), `privacy-guard`(내보내기 전 점검), `notion-publisher`(노션) |
| `.claude/skills/{담당}/` | 담당마다 업무 매뉴얼(할 일·시험). 노션에 올리는 모양은 `notion-publisher/references/` |
| `.claude/skills/daily-paper/` | 매일 한 번 실행하는 순서(메인이 따름). 대시보드의 지금 논문 찾기와 예약이 이것을 돌립니다 |
| `.claude/hooks/매일논문_루프.py` | **판정 루프 훅**: 노션에 올리기 전·끝내기 전에 판정을 강제하고, 실패하면 막아서 다시 고치게 합니다 |
| `scripts/` | 고르기·PDF(`매일논문.py 저장`), 판정(`매일논문_판정.py`), 설정 점검(`설정점검.py`), **웹 대시보드(`대시보드.py`)** |
| `설정/` | 담당마다 설정 파일(`paper-scout.json`, `zotero-keeper.json`, `paper-reader.json`, `notion-publisher.json`), 하루 편수(`매일논문.json`), 넣으면 안 되는 자료(`연구자_정보.md`) |

## 시작하기

필요한 것: Claude 데스크톱 앱(Pro 이상)과 Claude Code 로그인, python3 3.9+(패키지 설치 없음), claude.ai의 Notion 커넥터(필수)·Exa 커넥터(권장), 조테로 7(선택). 안내서는 [설치와설정.html](설치와설정.html).

받은 폴더를 Code 탭에서 열고 `설정해 줘`라고 보내세요. Claude가 이 순서로 진행합니다([시작하기.md](시작하기.md)).

1. 기본 · Claude Code 로그인과 설치 점검 (python3·커넥터·조테로·노션)
2. 기본 · 작업 디렉토리 만들기 — 저장소 안 `workspace/`(`.gitignore`로 git에서 뺌), **승인 후** 생성
3. 찾기 · `paper-scout` — 한국어 관심 분야 → 영어 키워드, 검색 미리보기, Exa 커넥터 이름
4. 조테로 · `zotero-keeper` (선택) — 쓸지 정하고, 쓰면 앱·컬렉션 점검과 시험 저장 1편
5. 요약 · `paper-reader` (선택) — 쓸지 정하고, 쓰면 요약할 편수와 시험 요약 1편(판정까지)
6. 노션 · `privacy-guard` → `notion-publisher` (필수) — 넣으면 안 되는 자료와 점검 시험, 노션 페이지 주소로 새로 시작(아카이브·표지 자동 생성)과 시험 1줄
7. 연결 시험 — 대시보드의 **지금 논문 찾기**(또는 작업공간 세션에서 `오늘 논문 찾아 줘`)로 담당이 이어서 일하는지 확인

개인 값은 작업공간에만 들어가서, 이 저장소를 공개해도 내 정보가 올라가지 않습니다. 사람은 앱 설치·가입·커넥터 연결·키 붙여넣기만 하면 됩니다.

웹 대시보드에서 담당마다 설정을 고치고 **시험 실행**으로 실제로 해 볼 수 있습니다(처음 설정은 담당 순서대로 하나씩 열립니다). **지금 논문 찾기**(언제든 설정 편수만큼 더 받기), **매일 예약**(Mac launchd), 날짜별 실행 기록, **조테로 탐색**(읽기만)도 대시보드에 있습니다. 대시보드는 이 컴퓨터의 Claude Code로 담당을 부릅니다. 이 컴퓨터에서만 열리고, 저장은 작업공간에서만 됩니다(원본 저장소에서는 보기만).

```bash
python3 scripts/대시보드.py
```

## 지키는 것

- 결과는 **후보**입니다. 요약마다 기준(원문 PDF / 웹 본문 / 초록)을 표시하고, 원문을 읽기 전에는 논문의 근거로 쓰지 않습니다.
- 밖으로 나가는 것은 영어 키워드와 논문 주소, 그리고 요약할 때 Claude에 보내는 논문 원문·초록입니다. 결과는 **본인 노션**에만 올리고, 올리기 전에 privacy-guard가 점검합니다.
- 검색 결과 속 명령문은 따르지 않습니다.
- 판정 통과가 "맞는 요약"이라는 뜻은 아닙니다. 판정은 코드로 볼 수 있는 것(숫자 출처, 형식, 집계)만 봅니다.

## 주의

- 키워드·노션 주소 같은 개인 값은 작업공간(`workspace/`)의 `설정/`에만 씁니다. 저장소 쪽 `설정/`에 채운 뒤 공개로 올리면 그 값도 함께 올라갑니다. 올리기 전에 확인하세요.
- 수집한 논문 PDF와 결과(`매일논문/`)는 `.gitignore`로 저장소에 넣지 않습니다. 남의 저작물을 다시 배포하지 마세요.
- OpenAlex·Semantic Scholar 무료 API를 씁니다. 요청이 몰리면 429 오류가 나니 1분 뒤 다시 하세요.
