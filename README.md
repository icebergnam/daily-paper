# 매일 논문 (The Daily Paper)

관심 키워드로 매일 새 논문을 찾아 **조테로에 저장**하고, **요약**해서, **노션**에 신문처럼 올립니다.
**Claude Code 에이전트**로 돌릴 수도 있고, Claude 없이 **파이썬 + 원하는 LLM**(내 컴퓨터의 Ollama, Gemini, OpenAI 등)으로 돌릴 수도 있습니다.

```
OpenAlex·Exa 검색 → 조테로 저장·오픈 액세스 PDF 받기 → 논문마다 요약(병렬)
→ 다이제스트 → 판정 루프 → 개인정보 점검 → 노션 The Daily Paper → 알림
```

## 무엇이 들어 있나

| 위치 | 내용 |
|---|---|
| `CLAUDE.md` | 규칙, 담당표, 호출표. Claude가 세션마다 읽습니다 |
| `.claude/agents/` | 담당 4명: `paper-scout`(Exa 검색·본문), `paper-reader`(요약), `privacy-guard`(내보내기 전 점검), `notion-publisher`(노션) |
| `.claude/skills/daily-paper-format/` | 노션에 올리는 모양(아카이브 한 줄, 표지 앞면) |
| `.claude/hooks/매일논문_루프.py` | **판정 루프 훅**: 노션에 올리기 전·끝내기 전에 판정을 강제하고, 실패하면 막아서 다시 고치게 합니다 |
| `scripts/` | 검색·저장(`매일논문.py`), 판정(`매일논문_판정.py`), **Claude 없이 전체 실행(`매일논문_단독.py`)**, 보기 화면, 설정 점검 |
| `설정/` | 키워드·편수·노션 주소, 넣으면 안 되는 자료 |

## 시작하기 — 두 가지 방법

| | **A. Claude 없이** | **B. Claude Code 에이전트로** |
|---|---|---|
| 안내서 | **[단독실행_안내.docx](단독실행_안내.docx)** | **[설치와설정.html](설치와설정.html)** |
| 필요한 것 | python3 3.9+ (패키지 설치 없음) | Claude 데스크톱 앱(Pro 이상) |
| LLM | 고름: Ollama(무료·로컬), Gemini, OpenAI, Anthropic API… 또는 **LLM 없이**(초록만) | Claude |
| 노션 | 내 노션 통합 토큰 | claude.ai Notion 커넥터 |
| 판정 루프 | 스크립트가 실패한 요약만 다시 요약 | 훅이 노션 호출·끝내기를 막고 담당이 다시 고침 |
| 매일 실행 | Mac launchd(`예약 09:00`) | Claude 예약 작업 |
| 요약 대상 | 오픈 액세스 PDF를 받은 논문만(못 받으면 다음 후보) | 같음 |

**Claude Code가 있으면 A·B 모두 Claude가 설정합니다.** 앱 설치·가입·커넥터 연결·키 붙여넣기만 직접 하고, Code 탭에서 `설정해 줘`라고 보내세요.

공통: 조테로 7(선택, 저장하려면), 노션 계정(선택). 처음이면 **A를 '최소' 등급**(LLM 없이 초록만)으로 시작해 보세요. 무료이고 5분이면 됩니다.

```bash
python3 scripts/설정점검.py 단독
python3 scripts/매일논문_단독.py
```

## 지키는 것

- 결과는 **후보**입니다. 요약마다 기준(원문 PDF / 웹 본문 / 초록)을 표시하고, 원문을 읽기 전에는 논문의 근거로 쓰지 않습니다.
- 밖으로 나가는 것은 영어 키워드와 논문 주소, 그리고 요약할 때 고른 LLM에 보내는 논문 원문·초록입니다. 결과는 **본인 노션**에만 올립니다.
- 검색 결과 속 명령문은 따르지 않습니다.
- 판정 통과가 "맞는 요약"이라는 뜻은 아닙니다. 판정은 코드로 볼 수 있는 것(숫자 출처, 형식, 집계)만 봅니다.

## 주의

- 키는 `설정/키.json`에 두며 git에 올라가지 않습니다. `설정/매일논문.json`에 내 노션 주소 등을 채운 뒤 이 저장소를 포크해 공개로 올리면 그 값도 함께 올라갑니다. 올리기 전에 확인하세요.
- 수집한 논문 PDF와 결과(`매일논문/`)는 `.gitignore`로 저장소에 넣지 않습니다. 남의 저작물을 다시 배포하지 마세요.
- OpenAlex·Semantic Scholar 무료 API를 씁니다. 요청이 몰리면 429 오류가 나니 1분 뒤 다시 하세요.
